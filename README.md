# Crypto Portfolio Watchlist

A simple static cryptocurrency portfolio watchlist built with HTML and CSS.

## Features

* Cryptocurrency watchlist
* Clean responsive layout
* Bitcoin, Ethereum and Solana examples
* No API keys
* No external dependencies
* Can be hosted with GitHub Pages

## Project Structure

```text
crypto-portfolio-watchlist
│
├── index.html
├── style.css
├── README.md
└── LICENSE
```

## Development Branches

This repository demonstrates a simple Git branching workflow.

### `main`

Stable base version of the project.

### `feature/dark-mode`

Adds a dark mode interface.

### `feature/portfolio-stats`

Adds basic portfolio statistics.

## Purpose

This project is a small educational Web3/frontend example created to practice static web development and Git branching.

The displayed prices are static demonstration values and are not live market data.
